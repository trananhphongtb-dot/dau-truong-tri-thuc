# Đấu Trường Trí Thức

Game hỏi đáp kiến thức cho Android, 3 phần thi: **Khởi động – Đấu Trí – Về Đích**.

## Bản 0.1.0 (chơi thử ngoại tuyến)
- Luyện tập một mình
- Luyện với 1–3 máy (Dễ / Vừa / Khó)
- 4133 câu hỏi, 12 lĩnh vực, ưu tiên câu chưa gặp
- Tiếng đồng hồ, chuông, giọng đọc chào mừng (tiếng Việt)

## Lấy file APK
Mỗi lần đẩy code lên nhánh `main`, GitHub Actions tự build.
Vào tab **Actions** → chọn lần chạy mới nhất → mục **Artifacts** → tải `DauTruongTriThuc-debug`, giải nén ra file `.apk` để cài.

## Sắp làm
Đăng nhập Google, thi trực tuyến 2–4 người, phòng chờ, kết bạn, xếp hạng tuần/tháng/năm, lời mời qua thông báo.
